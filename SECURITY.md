# Security and Responsible Use

This repository contains website templates, digital-product interfaces, and application starter code.

- Do not enter real patient information, confidential legal-client data, passwords, identity documents, API keys, or production credentials into an unreviewed deployment.
- Do not assume that an interface or starter generator supplies production-grade authentication, encryption, backups, logging, or access controls unless those controls have been implemented, tested, and independently reviewed.
- Replace sample business information and contact details with verified, authorized content before publication.
- Review applicable privacy, data-protection, accessibility, and professional requirements before deploying a website or application for a real business.
- Report suspected security issues privately to the repository owner before publishing technical details.
