# Security

This repository contains public portfolio demonstrations and prototypes.

- Do not enter real patient information, confidential legal-client data, passwords, or other sensitive personal information into demo applications.
- Do not assume that a prototype provides authentication, encryption, backups, or production-grade data protection unless those features have been independently reviewed and tested.
- If you identify a security issue in one of these demos, please contact the repository owner privately before publishing technical details.

These projects are not a substitute for a professional security review before production deployment.
